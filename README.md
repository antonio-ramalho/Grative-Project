# Grative 🤝

## 📌 Sobre o Projeto
O **Grative** é uma plataforma desenvolvida para centralizar e otimizar doações, conectando doadores privados e empresas a Organizações da Sociedade Civil (OSCs) e ONGs. O sistema funciona como uma rede social focada no terceiro setor, permitindo que as instituições criem campanhas de arrecadação, interajam com a comunidade, registrem despesas e gerem relatórios de impacto. 

Um dos grandes diferenciais do projeto é o cálculo de um **Trust Score** (Pontuação de Confiança) para as OSCs, baseado em suas postagens, relatórios e documentos na plataforma, facilitando acordos e parcerias com o setor privado.

## 🚀 Tecnologias e Arquitetura
O MVP (Produto Mínimo Viável) foi construído sem o uso de frameworks pesados, focando em uma arquitetura limpa em camadas (Views, Models, Resources) para separar a lógica de negócios da interface.
* **Linguagens:** PHP, JavaScript, HTML5, CSS3.
* **Banco de Dados/Integrações:** Firebase.
* **Inteligência Artificial:** Integração com a API do Gemini.
* **Design e Prototipagem:** Figma (com aplicação de System Design).
